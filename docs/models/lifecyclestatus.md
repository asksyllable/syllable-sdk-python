# LifecycleStatus

Effective deprecation state of a model, resolved against a reference date.

## Example Usage

```python
from syllable_sdk.models import LifecycleStatus

value = LifecycleStatus.ACTIVE
```


## Values

| Name         | Value        |
| ------------ | ------------ |
| `ACTIVE`     | active       |
| `DEPRECATED` | deprecated   |
| `RETIRED`    | retired      |
